## Overview

A scientific early screening tool designed to help identify behavioral tendencies related to autism spectrum in children. BHIMAC provides a structured, research-based questionnaire to assist parents and professionals in recognizing early signs of autism.

## Problem / Background

This project was developed for a client, Malang Autism Center. The previous version of the BHIMAC application had an outdated and less engaging UI/UX, was not responsive or interactive, and provided only basic screening functionality. It lacked authentication and authorization features, as well as dedicated dashboards for both administrators and users. The application was also not integrated with the WordPress-based website and had several bugs.

## Solution

Redesigned the BHIMAC application’s UI/UX to make it more responsive, interactive, visually engaging, and modern. Integrated the WordPress-based website with the BHIMAC application and implemented custom authentication and authorization features, along with dedicated dashboards for both administrators and users. Additionally, I fixed existing application bugs.

## Challenges

Integrating the WordPress-based website with the BHIMAC application was challenging due to the need to bridge the two systems while maintaining a clean and scalable architecture. To address this, I developed a custom framework using native PHP and implemented an MVC-based Service-Repository architecture to integrate WordPress features and APIs with the BHIMAC application.

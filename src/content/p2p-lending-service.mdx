## Overview

P2P Lending Service is a RESTful backend API designed to support peer-to-peer lending transactions. Developed as the final project of the Investree virtual internship program, the service provides secure user authentication, loan management, and transaction history tracking.

## Problem / Background

Peer-to-peer lending platforms require secure and reliable backend systems to manage loan applications and transactions. These systems must enforce access control, support configurable loan terms, track loan status changes, and provide users with organized transaction records.

## Solution

Developed a RESTful API using Spring Boot to manage lending-related operations. Implemented OAuth2-based authentication with JWT for secure access, loan creation with customizable repayment tenor and interest rates, loan status updates, and paginated transaction history with status-based filtering.

## Key Features

- Authentication & Authorization
- Loan Management
- Customizable Loan Tenor
- Configurable Interest Rates
- Loan Status Management
- Paginated Transaction History
- Transaction Status Filtering

## Overview

FanPaper Engine is a macOS live wallpaper application that transforms videos into dynamic desktop backgrounds. It provides a simple way to personalize the desktop with a wallpaper management, video importing, and multi-display support, delivering a more immersive desktop experience without watermarks.

## Problem / Background

Static desktop wallpapers offer limited personalization, while setting up video-based live wallpapers can require additional tools or complicated workflows. Users also need a convenient way to manage their wallpaper collections and enjoy consistent experiences across multiple displays.

## Solution

Developed a macOS desktop application that enables users to import videos and use them as live wallpapers. Implemented wallpaper management functionality and multi-display support, alongside a web platform built with Next.js and TypeScript to support the project's online presence and user-facing features.

## Key Features

- Import video into live wallpaper
- Wallpaper management
- Multi-display support
- watermark-free experience

## Overview

Open Music API is a RESTful backend service for music and playlist management, inspired by Spotify. Developed as the final project of the FGA Backend Developer training program in collaboration with Dicoding, the application provides APIs for managing songs, albums, and playlists, with authentication, authorization, and additional features for collaboration and data export.

## Problem / Background

Music management platforms require reliable backend services to organize songs, albums, and playlists while ensuring secure access to user-specific resources. Features such as album likes, collaborative playlists, file uploads, and data exports also introduce additional requirements for data consistency, performance, and background processing.

## Solution

Developed a RESTful API using Hapi.js to handle music catalog management, playlist operations, and user authentication. Integrated PostgreSQL for persistent data storage, Redis for caching, and RabbitMQ for message-based background processing. Implemented album cover uploads and playlist exports delivered via email as JSON files to support additional music management workflows.

## Challenges

One of the main challenges was coordinating asynchronous operations for playlist exports and email delivery without slowing down API responses. Integrating RabbitMQ for background processing required defining reliable message-handling workflows. Another challenge was balancing data consistency and performance when managing relational music data, collaborative playlists, and frequently accessed resources.

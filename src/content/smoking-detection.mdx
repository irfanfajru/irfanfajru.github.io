## Overview

Smoking Detection While Driving Using YOLOv7 is a web-based image detection system developed as a Bachelor's thesis project in Informatics at Ahmad Dahlan University. The application uses a two-stage YOLOv7 object detection pipeline to identify motorbike riders who are smoking by detecting riders and then identifying cigarettes within their bounding boxes.

## Problem / Background

Smoking while riding a motorcycle can distract riders and potentially compromise road safety. Identifying this behavior from images can be challenging because cigarettes are small objects that may be difficult to detect in complex scenes. This project explored the use of computer vision and deep learning to detect potential smoking behavior from uploaded images.

## Solution

Developed a web application that combines a Next.js frontend, a Flask backend API, and a trained YOLOv7 object detection model. Users can upload images through the web interface, which are processed by the backend to detect motorbike riders and identify cigarettes within the detected rider regions. The system returns annotated images with bounding boxes, detection labels, confidence scores, and a summary of detected objects.

## Challenges

One of the main challenges was detecting small cigarette objects in images where riders, motorcycles, and surrounding environments could introduce visual complexity. To address this, the system used a two-stage detection approach: first detecting motorbike riders, then searching for cigarettes within each rider's bounding box.

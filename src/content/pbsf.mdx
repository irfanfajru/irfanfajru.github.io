## Overview

Playbook Sales Force is a mobile and web-based application developed to monitor the daily activities and performance of Telkomsel Sales in Balikpapan. The system use GPS-based checkin, task documentation, and centralized web reporting to support sales activity monitoring and performance evaluation.

## Problem / Background

Monitoring sales activities across multiple field locations requires accurate activity records, reliable task documentation, and timely performance reports. Without a centralized monitoring system, collecting field activity data and reviewing individual sales performance can be time-consuming. A structured solution was needed to connect mobile-based field activities with web-based monitoring and reporting.

## Solution

Developed a sales activity monitoring system consisting of a mobile application and a web dashboard connected through APIs. The mobile application supports GPS-based check-in, task documentation, and checkout, while the web application provides dashboards, activity logs, daily reports, master data management, and user administration.

## Challenges

One of the main challenges was integrating mobile field activities with the web monitoring system to ensure that check-in records, task documentation, and checkout data could be synchronized reliably. Supporting GPS-based activity tracking also required coordination between mobile-submitted location data and the application's validation rules. In addition, organizing activity logs and daily reports required consistent data handling to support accurate sales monitoring.

Playbook Sales Force provides a centralized system for monitoring Telkomsel Sales activities in Balikpapan. By connecting mobile field operations with web-based reporting, the application supports structured activity documentation, easier daily monitoring, and more organized performance evaluation through reports.

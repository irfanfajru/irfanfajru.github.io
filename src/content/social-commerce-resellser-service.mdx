## Overview

Social Commerce Reseller Service is a backend API designed to support reseller operations within a social commerce platform. Developed as the final project of the Evermos virtual internship program, the service provides core functionality for managing user accounts, stores, products, shipping addresses, and transactions using Golang and MySQL.

## Problem / Background

Social commerce reseller platforms require reliable backend services to manage product information, reseller stores, user data, and transaction workflows. Without a structured API, these operations can become difficult to maintain and integrate with external services. A centralized backend was needed to organize reseller-related data, enforce access control, and support interactions with third-party regional APIs.

## Solution

Developed a RESTful backend API using Golang and MySQL to support essential social commerce reseller workflows. The service handles authentication and authorization, user and store management, product and category operations, shipping addresses, and transactions. It also integrates with third-party regional APIs to extend the service's functionality.

## Challenges

One of the main challenges was maintaining consistent relationships between users, stores, products, addresses, and transactions. Each operation needed to validate incoming data and preserve data integrity across related entities. Integrating third-party regional APIs also required handling external responses and mapping their data into the application's workflows without disrupting the core service.
